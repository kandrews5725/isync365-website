Security & Compliance

Built with PII lifecycle and access control in mind from day one.

As a contact distribution platform, everything below reflects how contact data moves, where it lives, and what happens when someone's access changes.

Where your contact data actually lives

On Outlook, contacts are written directly into each person's own mailbox inside your organization's Microsoft 365 tenant. On mobile, iSync365 uses a dedicated, company-provisioned CardDAV account for every device — never an account tied to anyone's personal cloud service. Whether a device is company-managed or personal and unmanaged, the delivery account is created and controlled entirely on our side, not tied to any individual's personal identity.

Two ways in, one standard of security

For company-managed devices, iSync365 can deploy a configuration profile the same way most enterprise tools do — the credential itself is never visible to the end user. For personal or unmanaged devices, setup is manual: an admin provides a secure passphrase, and can regenerate it at any time, instantly invalidating the old one.

Automatic revocation — no manual intervention, no exceptions

When an employee is unassigned from a list, the associated contacts are automatically removed from every device — nothing for your team to track down, delete, or double-check. It happens the same way every time, with no one having to make it happen.

Flexibility that doesn't compromise data

Reassigning someone — whether they're leaving the company or just changing roles — automatically clears the associated contacts from their personal device. Nothing for your team to manually delete, and nothing left behind afterward.

Built on modern standards, not a protocol being phased out

Many contact-sync tools rely on an older Microsoft protocol called Exchange ActiveSync (EAS) — one Microsoft itself is actively retiring, with real security issues documented in older versions along the way. iSync365 doesn't use EAS at all. Mobile devices connect through CardDAV, an open, modern standard, and Outlook sync runs through Microsoft's current Graph platform — both built around today's security practices, not a protocol on its way out.

Zero-touch delivery, without requiring MDM

Most tools can only deliver contacts zero-touch if the device is enrolled in MDM. Without MDM, the usual fallback path requires the employee to manually sign in to finish setup — there's no way around that step. iSync365's CardDAV connection doesn't have that limitation: it works the same whether a device is managed or not, so setup stays zero-touch either way, with nothing for the employee to do.
